# SHiMO 内容发布助手

这是一个本机 Chrome 扩展，把 md-wechat 当前排版结果粘贴到微信公众号、抖音和小红书的编辑页面。

## 安装

1. 在 md-wechat 项目目录运行 `npm run dev:ensure`。
2. 打开 Chrome 的 `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本目录下的 `extension/` 文件夹。
5. 保持 md-wechat 的 `http://127.0.0.1:5173/` 页面打开并选中要发布的文章。

## 使用

1. 打开微信公众号、抖音或小红书的创作编辑页。
2. 点击 Chrome 工具栏中的“SHiMO 内容发布助手”。
3. 点击“粘贴并保存草稿”。
4. 检查标题、正文、图片和平台显示效果。

扩展只负责草稿，不点击发布、提交审核或群发。平台页面结构变化时会提示“未找到”，不会盲目写入其他页面。
